## Assignment Title
Technical Analysis using R – Visualization Phase
## Project Description
This project is an interactive stock portfolio dashboard created using R Shiny. It retrieves historical stock data from Yahoo Finance and visualizes stock prices using interactive chart options. The dashboard includes technical indicators such as Moving Averages, RSI, and MACD, and generates Buy, Sell, and Hold trading signals.
